# Дири и наследници / Trails and Heirs — сайт

Статичен сайт с 12-те разказа на два езика. Чист HTML+CSS, без JavaScript, удобен за
мобилно четене, с тъмна тема по системната настройка. Същият стил като първия сборник.

Продължение на **Товари и наследства / Cargoes and Legacies**:
https://simeonbodurov.github.io/vorkosigan-stories/

## Структура

- `index.html` — двуезична начална страница с връзки към двете издания и към първия сборник
- `bg/` — 12 разказа + съдържание + предговор + бележка в края
- `en/` — the same twelve stories + contents + preface + closing note
- `style.css` — общият стил (споделен с първия сборник)
- `diri-i-naslednitsi.epub`, `trails-and-heirs.epub` — двете издания за сваляне

Всяка страница има кръстосана връзка към другия език и навигация предишен/следващ разказ.

## Хостване

Тази папка е предназначена да стои като подпапка `trails/` в корена на хранилището
на първия сборник (`vorkosigan-stories`). След качване сайтът е на:

    https://<потребител>.github.io/vorkosigan-stories/trails/

Всички връзки вътре са относителни, тъй че папката работи веднага, без промени.
На началната страница на първия сборник трябва да има връзка насам — по един ред
във всяка езикова секция:

    <p class="muted">Continued in <a href="trails/en/index.html">Trails and Heirs</a> &mdash; twelve more stories</p>
    <p class="muted">Продължава в <a href="trails/bg/index.html">Дири и наследници</a> &mdash; още дванадесет истории</p>

`style.css` тук е самостоятелно копие, за да останат двете книги независими.

Работи и като самостоятелен сайт (GitHub Pages, GitLab Pages, Netlify, Cloudflare Pages)
— просто качи съдържанието на тази папка в корена на отделно хранилище.
